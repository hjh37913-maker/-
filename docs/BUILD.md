# Build and troubleshooting
Requirements: CMake >=3.20, C++20 compiler and build tool; no third-party runtime dependency. Windows: install Visual Studio 2022 and the Desktop development with C++ workload, including MSVC and CMake, then use its developer command prompt. Commands and launch paths are in README. `-DBUILD_TESTING=OFF` omits tests; CTest defaults to on. Multi-config builds require matching `--config`/`-C` settings; if no compiler is found install the C++ workload, and if CMake is missing install it and reopen the terminal. For a Unix sanitizer build use `-DCMAKE_CXX_FLAGS='-fsanitize=address,undefined -fno-omit-frame-pointer' -DCMAKE_EXE_LINKER_FLAGS='-fsanitize=address,undefined'`. No Windows build has been verified.
