# Input experiment

`nightfall::input::Mapper` is a platform-neutral, digital-button state aggregator. A caller explicitly connects a numeric device ID and sends button changes. Actions have case-sensitive nonempty names and one or more numeric control bindings. An action is active when any connected device has any bound control pressed. Controls use one application-defined namespace shared across devices: there is currently no per-device profile or device-type translation. Duplicate binding and connection return false; updating an existing button to the same state succeeds and is idempotent. Unknown devices reject button updates. Disconnect removes the device and all its pressed state, and reconnect starts neutral; bindings persist. Rebinding affects queries immediately. `stats()` reports current devices, pressed device/control pairs, actions and bindings.

The caller must serialize all mapper operations and supply stable IDs, events and control normalization. This is a synthetic input abstraction only. There is no operating-system event loop, keyboard, mouse, XInput, DualSense, analog axes, device discovery, persisted profiles, game guest interfaces or actual reconnect detection. A caller can report reconnect events manually, but physical reconnection has not been tested. This module does not control a PS5 game.
