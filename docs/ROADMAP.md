# Roadmap
0. Public feasibility research: started; uncertainties remain.
1. Architecture: initial dependency graph created.
2. Build and testing: CMake and Linux tests established; Windows pending.
3. Core: bounded lifecycle slice, not a full module system.
4. CPU: interpreter subset with ADD differential checks; broader tests and design study next.
5–9. GPU, memory model, runtime, storage/input and compiler research: experimental byte-granular memory mappings and permissions a bounded synchronous host-file reader with CRC-32, a synthetic digital input mapper, a CPU-only graphics experiment and a standalone logical timer queue only; all guest compatibility remains unimplemented.
10–11. Integration and performance: synthetic CPU/memory integration only; one synthetic ADD baseline established; broader benchmarks needed before optimization.
12–13. GTA VI compatibility and final validation: blocked on lawful access, documented interfaces, substantial implementations and real tests. No phase is claimed complete merely because preliminary work started.
