# Work block: CPU, SIMD and synthetic process memory

- Start: 2026-11-19 15:11:46 UTC. Work block target: one full hour.
- Implemented selected ADC/SBB, CMOVcc/SETcc, REX-prefixed 32-bit operations, multi-byte NOP, and restartable step-bounded string instructions with direction and repeat handling.
- Added 16 XMM registers and a deliberately limited SSE/SSE2 integer/move subset, with explicit modeled alignment-fault propagation. No complete SIMD, floating-point, XSAVE, guest signal delivery or console GPU is claimed.
- Added a bounded synthetic anonymous mmap/mprotect/munmap arena; no guest syscall or address is forwarded to host OS. The arena differs intentionally from Linux and is not a security sandbox.
- Added original static Linux fixtures, including GCC-compiled C hash, SSE2 vector and anonymous-allocation programs. Their output was checked against native Linux execution and independent Python references. A seeded optional stress run checked 45,000 compiled-fixture executions against both references (`scripts/stress_linux_compiled.py`, seeds 441147 and 441148, 15,000 input sets).

Native differential testing covers selected instruction forms; 50,000 additional anonymous-memory operations were checked against a separate software model, and 1,024 cases against native private anonymous mappings. Counts are test cases, not an estimate of completeness.
- Added a per-step instruction-fetch cache. An unpinned synthetic ADD microbenchmark showed substantially shorter times in three paired samples; exact measurements and caveats are in `docs/PERFORMANCE.md`. No game performance claim.
- Windows x64 CLI and portable tests cross-compiled with Zig; no Windows runtime/device was available. No PS5 or GTA VI executable was tested.

All final checks above passed.
